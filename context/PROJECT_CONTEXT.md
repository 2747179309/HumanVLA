# 项目上下文

## 项目定位

论文以低成本 Human Video 到 Language-Aligned Robot Policy Dataset 的数据构建方法为主，研究普通人类操作视频如何转化为可用于机器人模仿学习和 VLA 策略学习的语言对齐数据。

本项目当前不做完整 OpenVLA 训练，也不以提出新的大型 VLA 模型或通用机器人基础模型为贡献。

## 当前优先级

当前最高优先级是建立并验证 DeepSORT MOT 与 OpenPose 标注流水线：YOLO 人体检测、DeepSORT 局部轨迹、人工复核、全局人物映射、BODY_25 提取、骨架与人物关联，以及动作和语言标注。

## 后续实验

- E1：动作语义分段。
- E2：文本与动作细粒度对齐。
- E3：骨架质量、平滑和质量控制。
- E4：人体动作到机器人状态与动作表示的转换。
- E5：使用 ACT 等轻量策略验证数据可用性。
- E6：关键组件消融实验。

已有 LeRobot、PushT、ACT 小规模训练经验，但所有软件、CUDA 和训练假设都需要在这台新电脑上重新核对，不能直接视为已复现。

## 交付目标

- 有真实实验支撑的英文论文初稿。
- 可复现的实验代码与配置。
- 合规采集和标注的自采数据。
- 可追溯的结果表、图和实验日志。
