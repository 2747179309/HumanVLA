## 一、必须独立解释的概念

- [ ] 3. 阶段边界为什么需要保护——给出一个具体的 E001 例子（如 grasp→lift）
- [ ] 4. Savitzky-Golay 的窗口宽度如何影响平滑效果（w 太小 vs w 太大的后果）
- [ ] 5. One Euro 的自适应截止频率机制——为什么快速运动时它减少平滑
- [ ] 6. Kalman 滤波中 \(Q\) 和 \(R\) 的含义——增大 \(R\) 会怎样？增大 \(Q\) 会怎样？
- [ ] 7. "最平滑的方法"为什么不一定是最好的方法
- [ ] 8. 合成污染实验如何解决"真实错误帧没有 ground truth"的问题
- [ ] 9. 上臂-前臂骨骼约束为什么是软约束而不是硬约束
- [ ] 10. 训练集/验证集/测试集隔离的目的是什么——如果不隔离会发生什么
- [ ] 11. 消融实验中 `No Quality` 和 `No Phase` 分别移除什么——预期分别影响哪些指标
- [ ] 12. 为什么 RMSE 是我们的主要指标，而不是 Jerk

## 二、必须手算或推导的公式

- [ ] 1. 质量权重公式：给定 conf=0.85, mask=keep(1.0), source=raw(0.8)，计算 \(q_t\) 的值
- [ ] 2. 加速度平滑项：给定三帧位置 [100, 102, 107]，计算 \(\|x_3 - 2x_2 + x_1\|^2\)。如果这是一个 clean 帧序列，这个值应该大还是小？
- [ ] 3. 速度中央差分：给定帧 t-1, t, t+1 的位置，写出 \(v_t\) 的计算式。为什么用中央差分而不是前向差分？
- [ ] 4. 归一化 Jerk 公式中 \(T^5/L^2\) 的作用——如果运动变长 2 倍（T×2），归一化 Jerk 如何变化（假设路径相同）？
- [ ] 5. 骨骼约束：已知 RShoulder=(500, 200), RWrist=(550, 280), \(L_{\text{upper}}=170\), \(L_{\text{forearm}}=150\)，估算 RElbow 的可能位置（用纸笔画图）

## 三、必须自己运行的实验

- [ ] 1. 对 valid 帧段施加 σ=5 px 高斯噪声，分别用 SG(w=5)、One Euro、Kalman CV 处理，计算 RMSE。哪种方法最好？为什么？
- [ ] 2. 对一个包含 grasp→lift 边界的 30 帧段，分别用 SG 和 "不跨阶段平滑" 处理。观察边界处的加速度曲线差异
- [ ] 3. 改变 Kalman 的观测噪声 \(R\)（0.01, 0.1, 1.0），观察滤波轨迹的平滑度和 RMSE 的变化

## 四、10 个检查问题

**Q1**：frame 64-65 RWrist 被 T07B 用 linear 修复，frame 64-65 RElbow 被 T07C-A 标记为 low_quality (mask)。这两个处理有什么不同？为什么 RElbow 不能也用 linear 修复？

**Q2**：如果我们在整个 345 帧上用 window=11 的 SG 滤波器，frame 105（grasp→lift 边界附近）的 RWrist 位置会如何受影响？

**Q3**：为什么我们在目标函数中惩罚加速度的**变化**（即二阶导数的变化 = Jerk），而不是直接惩罚位置的变化（速度）？

**Q4**：已知 Kalman CV 模型假设关节做匀速直线运动。在哪个 E001 阶段这个假设大致成立？在哪个阶段它会失败？

**Q5**：如果我们将一个 valid 帧的 \(q_t\) 错误地设为 0（mask），在优化中会发生什么？反之，将一个 mask 帧的 \(q_t\) 错误地设为 1 又会怎样？

**Q6**：为什么合成污染实验的训练集和测试集必须来自不同的帧段？如果我们在 frame 50-150 上调参，然后在 frame 51-151 上测试，有什么问题？

**Q7**：我们的方法在消融实验中，`No Bone` 条件（移除骨骼约束）对哪些帧的影响最大？

**Q8**：如果"我们的方法"在合成测试集上的 RMSE 比 Kalman CV 低 15%，但 Jerk 高 20%，我们应该如何向读者解释这个权衡？哪个方法更好？

**Q9**：我们需要为 E001 的每个阶段分别报告指标吗？为什么（不）？

**Q10**：如果我们不仅滤波 RWrist/RElbow，还滤波 Neck 和 RShoulder，会怎样？为什么我们的 corruption mask 中 Neck 几乎全是 valid？
